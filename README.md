# Discover Futures 4 · Unit 1 Music Review

A 15–20-minute review for Prep IS English: 14 multiple-choice questions and six one-sentence responses. Covers music vocabulary and effects, the Golden Record reading, music technology, focus and recommendations, descriptive language, and The Silent Forest. Describing trends is excluded.

## Netlify

Deploy this repository's `main` branch. No build command is needed. The publish directory is `dist`, configured in `netlify.toml`.

[![Deploy to Netlify](https://www.netlify.com/img/deploy/button.svg)](https://app.netlify.com/start/deploy?repository=https://github.com/sinanseden-eng/unit-1-music-review-questions)

## Printing and saving

- **Print review** at the top prints all 20 questions as a blank worksheet, without solutions.
- After completion, **Print / save my review as PDF** includes responses, model answers, explanations and the topic profile.
- **Save answer copy** downloads a text copy of the student's answers.
- Answers are saved in the current browser's local storage. They are not submitted to a server or teacher.

Multiple-choice answers are checked automatically. Students compare short responses using two criteria each. Topic feedback distinguishes automatic scores from self-checks to support a later self-evaluation form.

## Files

`dist/index.html`, `dist/style.css`, `dist/questions.js`, and `dist/app.js` form a dependency-free static site. Netlify's local state folder is ignored by Git.

Original review questions refer to Discover Futures 4 Student's Book Unit 1, class language work, and Denise Taylor's The Silent Forest. Source readings are not reproduced.
